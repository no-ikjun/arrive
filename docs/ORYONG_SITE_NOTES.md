# 오룡관 현장 정보 — 사용자 제공, 2026-11-12

이 문서는 사용자가 제공한 설명과 표시 지도에 대한 개발 참고 기록이다.
공식 시설 허용 조건, 실제 좌표, SDK 경로 검증이 완료됐다는 뜻이 아니다.
첨부 지도 원본은 docs/site-reference에 참고용으로 보관하며 앱 assets에 포함하지 않는다.

## 사용자가 설명한 내용

- 정문에서 오룡관으로 접근하는 도로는 기존 내비게이션으로 안내받는다.
- 최초 지도에서 노란 화살표 끝에 표시한 지점은 사용자가 잠시 하차 가능한 곳으로 설명했다.
- 오룡관 주변 주차장 1과 주차장 2는 서로 다른 후보이다.
- 주변 주차 공간이 없을 때 축구장 주차장, 그곳도 어려우면 대학원 기숙사 주차장을 고려한다.
- 정문 진입 직후 바로 좌회전할 수 없고, 일방통행이 있어 대체 주차장 접근에 우회가 필요하다.
- 첫 번째 추가 지도는 오룡관을 돌아 축구장 주차장으로 접근하는 차량 경로를 표시한다.
- 두 번째 추가 지도는 같은 접근 흐름에서 기숙사 쪽으로 가는 분기를 함께 표시한다.
- 사용자가 추가 지도(04-meeting-point.png)의 노란 체크/원 표시 지점을 만남 장소로 지정했다. 프로토타입에서는 이 위치를 기준으로 한다. 화면상의 이름은 임시로 "오룡관 주차장 1 입구 옆 만남 지점"을 사용한다. 공식 시설 명칭은 아니다.
- 하차 후에는 걸어서 이동할 수 있다고 설명했다. 구체적인 보행 경로와 무단차 여부는 미확인이다.

## 구현에 반영할 결정

1. 기본 내비게이션을 대체하는 서비스보다 하차·주차 대안·재합류의 연결에 집중한다.
2. 차량 경로와 보행 경로를 별도 데이터로 취급한다. 지도에 표시된 노란 선은 차량 접근 경로이다.
3. 주차 후보 순위와 실제 차량의 순회 경로는 별개이다. 거리만으로 후보를 정렬하거나 좌회전·유턴을 생성하지 않는다.
4. 운전자의 주차 후보가 변경돼도 동승자에게 약속한 만남 지점을 자동 변경하지 않는다.
5. 지정된 만남 지점을 차량 안내와 동승자 카드가 함께 참조한다. 위치 선택은 완료됐으며, 실제 좌표·보행 공간 경계·현장 표식은 별도 확인 대상이다. 지점 지정과 현장 검증 상태를 구분한다.
6. 주차장 1·2 분리 시 현재 Kotlin catalog와 서버 seed를 같은 catalogVersion으로 함께 갱신해야 한다.
   Claude 백엔드 작업과 충돌을 피하기 위해 이 메모 작성 시에는 contracts/ 및 backend/를 수정하지 않았다.

## 현재 지도만으로 확정할 수 없는 내용

- 주차장 1과 2의 선호 순서 및 각각의 정확한 차량 진입 좌표.
- 축구장 주차장까지 도착한 뒤 기숙사로 재탐색할 때 허용되는 전체 경로.
  두 번째 그림의 분기는 접근 중 선택지로 읽히며, 두 주차장을 연속 방문하는 경로가 모두 그려진 것은 아니다.
- 일방통행 구간의 정확한 시작·종료, 모든 회전 허용 여부.
- 지정 지점의 정확한 좌표, 보행 공간 경계 및 현장에서 식별할 수 있는 표식.
- 동승자가 하차 후 만남 지점으로 이동하는 경로, 운전자가 각 주차장에서 돌아오는 보행 경로.
- 외부 방문객의 주차 이용 조건, 계단·경사·문 개방, 보행 시간.

## 다음 확인

- 지정된 만남 지점의 이미지 기반 좌표 추정은 완료했다(아래 계산 기록). 만남 장소를 다시 선택하거나 사용자에게 좌표를 재입력받을 필요는 없다. 현장 표식과 보행 공간 경계는 추후 대조한다.
- 하차 지점 및 각 주차장 차량 진입구의 지도 핀 또는 링크 확보 후 좌표 추출·대조.
- NaviHelper가 생성하는 경로가 표시된 차량 통행 방향과 일치하는지 별도 검증.
- SDK 호출 결과만으로 실제 길안내가 성공했다고 표시하지 않고 결과/실패를 구분한다.

## 2026-11-12 이미지 기반 좌표 계산

- 만남 지점 추정값: **위도 35.22648, 경도 126.83947 (WGS84)**.
- 기준: 04-meeting-point.png의 노란 원 중심 부근 픽셀 (841, 428). 사용자의 손그림 범위를 대표하는 점이며 정밀 측량점이 아니다.
- 04 → 05 이미지 정합: SIFT 특징점 2,334개 인라이어, 중앙 잔차 0.226픽셀. 05 이미지에서 해당 지점은 약 (856.897, 323.636).
- 지리 기준: [Esri World Imagery](https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer)의 z19 타일. 다른 촬영 시기의 영상과 대응되는 특징점을 RANSAC으로 정합했다. 18개 인라이어, 중앙 잔차 약 0.91m. 이는 영상 간 정합 잔차이며 절대 위치 정확도가 아니다.
- 독립 축척 확인: 05의 자 양끝 (599, 101), (977, 394) 사이가 100.1m. 계산된 지리 변환에서는 약 100.4m로 약 0.3% 차이.
- 유사 변환과 일반 아핀 변환의 만남 지점 차이는 약 0.75m였다. 이것 역시 현장 측량 검증은 아니다.
- 원본 영상의 위치 오차, 건물 높이에 따른 영상 변위, 표시한 원의 범위 때문에 실제 절대 오차는 미확인이다. 개발 검토용으로 주변 20m를 함께 확인하되, 이를 보장된 오차 범위 또는 자동 도착 판정 반경으로 사용하지 않는다.
- [OpenStreetMap 오룡관 건물 윤곽](https://www.openstreetmap.org/way/1171604935)도 주변 형태 대조에 참고했다. 최종 변환은 건물 주소 대표점이 아닌 좌표가 있는 항공영상으로 계산했다.
- 지도 표시·프로토타입 데이터로 사용할 수 있는 추정치다. 정확한 도로 측면·보행 위치·정차 허용 여부는 별도 검증 대상이다.
- GeoJSON: `site-reference/meeting-point.estimated.geojson` (경도, 위도 순서). 계산 근거와 변환 행렬: `site-reference/meeting-point.calculation.json`.
- 백엔드 개발 중인 공유 계약/seed의 검증 상태는 변경하지 않았다. 앱에 연동할 때도 추정 위치와 현장 검증 완료 상태를 구분한다.
- 05-scale-reference.png: 사용자가 추가한 100.1m 자가 표시된 원본 위성사진. 지도 이미지는 참고 자료이며 앱 배포 자산에 포함하지 않는다.
