# arrive 시연 대본

## 전달할 한 문장

“자리가 없다고 한 번 알려주면, 이미 확인한 곳을 제외하고 다음 주차 후보를 골라줍니다. 주차한 뒤에는 먼저 들어간 동승자에게 합류하도록 안내가 이어집니다.”

## 2분 30초 설명과 조작

| 시간 | 화면과 조작 | 설명 대본 |
|---|---|---|
| 0:00–0:15 | 첫 화면·지도 | “처음 간 행사장입니다. 내비게이션은 도착했다고 하는데 주차장에 자리가 없습니다. 동승자는 먼저 입장하고, 운전자는 다음에 어디로 가야 할지 다시 찾아야 합니다.” |
| 0:15–0:30 | 시작 → 하차 확인 | “arrive는 이 도착 과정을 이어줍니다. 동승자를 내려주고 주차를 시작합니다. 동승자는 공유한 입구 안내로 먼저 건물에 들어갑니다.” |
| 0:30–0:55 | 주차장 1 → 자리 없어요 → 주차장 2 | “자리가 없으면 이 버튼을 누릅니다. 방금 확인한 곳을 이번 방문에서 제외하고 다음 후보를 자동으로 선택합니다. 후보를 다시 검색하거나 목록에서 고르지 않아도 됩니다.” |
| 0:55–1:15 | 다시 자리 없어요 → 축구장 후보 | “다음 곳에도 자리가 없다면 같은 동작으로 이어갑니다. 확인한 곳은 지도에 ×로 남고, 추천한 곳은 검정 P로 표시됩니다. 현재는 등록된 순서의 후보 추천이며 실시간 빈자리 정보는 아닙니다.” |
| 1:15–1:35 | 이곳으로 길안내 → 내비 목적지 → arrive 복귀 | “추천 결과를 확인하고 길안내를 누르면 Pleos 내비게이션에 목적지를 전달합니다. 위치와 기어 상태를 활용한 도착 확인 보조도 연결했습니다. 실제 하차·주차 여부는 사용자가 확인합니다.” |
| 1:35–2:00 | 주차 완료 → 휴대폰 연결 → 입구 | “주차를 마치면 안내를 운전자 휴대폰으로 넘깁니다. 동승자가 먼저 들어간 건물의 입구를 확인하고 이동합니다. 동승자의 조회 링크와 운전자의 합류 확인 권한은 구분합니다.” |
| 2:00–2:15 | 휴대폰 합류 확인 → 차량 완료 | “건물 안에서 만난 뒤 합류를 확인하면 차량과 웹에도 방문 완료가 반영됩니다. 차량 문을 닫은 뒤에도 같은 방문이 이어집니다.” |
| 2:15–2:30 | 핵심 화면·확장 방향 | “현재는 한 장소로 흐름을 검증했습니다. 시설별 후보·입구 데이터를 확장해 낯선 장소에서도 다음 행동을 쉽게 선택하도록 만들겠습니다.” |

## 제공 영상의 범위

`output/submission/arrive_demo.mp4`는 release 에뮬레이터의 실제 주차 추천 녹화와 앞서 운영 환경에서 확인한 웹 화면을 편집한 무음 소개 영상입니다. 하나의 방문을 끊김 없이 녹화한 영상이나 현장 주행 영상이 아닙니다. 모바일 화면은 390×844 Chromium 검증 캡처이며 실제 휴대폰 촬영은 아닙니다. 장면 자막에서 구분합니다. 실제 사용자 QR과 토큰은 포함하지 않습니다.

## 라이브 시연 준비

- Pleos Connect 2.1.0 ARM64/API 34, 2560×1440, 기어 P, 인터넷 연결.
- 위치·알림 권한을 허용하고 지도 타일과 서버 연결을 확인합니다.
- 기존 방문을 종료한 뒤 새 방문으로 시작합니다. 이전 QR은 재사용하지 않습니다.
- SDK 경로 요청은 내비를 전면에 띄웁니다. arrive 아이콘 또는 방문 알림으로 돌아오는 동작을 연습합니다. 앱 자동 복귀로 설명하지 않습니다.
- 현재 에뮬레이터의 내비 출발점은 성남으로 나타날 수 있습니다. 목적지 전달만 보여주고 270km/예상 시간을 현장 경로 검증으로 해석하지 않습니다.
- 좌표·보행 동선·이용 조건은 미검증이므로 실제 차량으로 시연하지 않습니다.
- 주차 후보를 모두 제외했을 때 현장 안내 확인 메시지가 나오고 같은 후보를 순환하지 않는 장면은 질의응답용으로 남깁니다.

## 예상 질문

**일반 내비와 무엇이 다른가요?** 주차 실패 후 같은 방문의 제외 기록을 유지하며 다음 후보를 고르고, 주차 후 입구·합류 안내까지 이어갑니다. 도로 경로 계산은 Pleos 내비게이션을 사용합니다.

**빈자리는 어떻게 아나요?** 현재는 알지 못합니다. 운전자의 자리 없음 입력으로 그 방문에서 제외하며, 다른 사용자에게 만차 정보로 전파하지 않습니다.

**왜 차량 앱이어야 하나요?** 차량의 위치·기어·주행 제한 맥락을 사용하고 큰 버튼으로 다음 주차 결정을 돕습니다. 내비 목적지를 직접 전달하고, 주차 후에는 휴대폰으로 안내를 넘깁니다.

**다른 곳에서도 쓸 수 있나요?** 화면은 방문 데이터를 사용하지만 현재 앱에 연결된 시연 장소는 한 곳입니다. 장소 선택·버전별 카탈로그 조회와 현장 검수가 다음 작업입니다.

**사업성은요?** 행사장·시설이 검수한 주차 후보와 입구 정보를 제공하고 참가 안내에서 유입을 만들 수 있습니다. 운영자용 안내 관리 유료 제공은 검증할 가설이며 현재 제휴·매출 실적은 없습니다.
