# 운전자 조작 줄이기 · 2026-11-14

## 구현 범위

| 상황 | 앱 동작 | 운전자 확인 |
| --- | --- | --- |
| 방문 시작 | 하차 지점 길안내를 함께 요청 | 시작 · 길안내 1회 |
| 하차 지점 근처 | 차량 위치 + P 6초 유지 시 하차 확인 문구 표시 | 동승자가 내렸는지 확인 1회 |
| 하차 확인 | 방문 단계 저장/기존 공유 전송 후 선택된 주차장 길안내 요청 | 별도 내비 버튼 생략 |
| 다른 주차장 선택 | 기존 후보 제외 + 다음 후보 길안내 요청 | 다른 주차장 1회 |
| 선택된 주차장 근처 | 차량 위치 + P 6초 유지 시 주차 확인 문구 표시 | 실제 주차 완료 확인 1회 |
| 주차 확인 | 위치 서비스 종료 + 휴대폰 연결 QR 표시 | 휴대폰에서 실제 합류 후 확인 |

길안내는 기존 제한을 유지한다. 현재 카탈로그가 위성사진 기반 추정값이므로 **debug 에뮬레이터에서만 경로를 요청**한다. 실제 차량에서의 경로 제공은 현장 검증된 차량 진입구·경로 데이터와 별도 제품 검토가 필요하다. SDK 요청/응답 실패 시 성공으로 표시하지 않고 ‘더 보기’에서 수동 재연결/길안내 재시도를 제공한다.

## 차량 데이터

- Pleos FusedLocation **1.1.3**: callback으로 차량 위치 수신. 화면 또는 활성 방문의 위치 서비스에서 연결을 유지. 공식 문서의 1.1.2는 Maven에 없었으며 실제 metadata에 제공되는 1.1.3을 사용했다.
- AAOS `CarPropertyManager`, `GEAR_SELECTION`: 읽기 전용 현재 변속 상태. 1초 간격 조회는 IO 스레드에서 실행한다. P 이외의 상태나 읽기 실패는 정차로 간주하지 않는다.
- `pleos.car.permission.FUSED_LOCATION`: 런타임 권한. ‘더 보기 → 알림·위치 허용’에서 요청한다. 현재 Pleos 에뮬레이터 권한 팝업은 자체 설명 누락으로 ‘알 수 없는 작업’이라고 표시한다.
- `android.car.permission.CAR_POWERTRAIN`: 일반 권한. 앱 설치 시 부여되는 읽기 권한이다.
- 위치는 차량 지도에만 파란 점으로 표시하며 방문/공유 API에 업로드하지 않는다. 주차장 빈자리, 동승자 위치, 실제 하차·주차 여부를 추론하지 않는다.
- 하차·주차 이동 중에는 알림/위치 권한을 받고 시작한 foreground service가 내비 사용 중에도 관측을 유지한다. 주차 확인/방문 종료/알림 끄기/권한 회수/2시간 제한에서 서비스를 종료한다. 서비스가 없고 앱도 보이지 않으면 연결과 관측값을 해제한다. 부팅·프로세스 종료 후 자동 재시작은 하지 않는다. 상세는 [연속 이용 개선](CONTINUITY_SETUP.md)을 참고한다.

## 판단 조건과 중복 방지

- 단계별 현재 목적지(하차 지점 또는 선택 주차장)의 45m 이내에서 근처 안내 시작, 65m 밖이면 해제한다. 이 수치는 시연용이며 현장 검증이 필요하다.
- 위치 timestampMillis가 현재 시스템 시각 기준 0~10초일 때만 수용한다. 동일/과거 타임스탬프 재전송은 관측 시간을 갱신하지 않는다. 이후 만료는 monotonic clock으로 판단한다.
- 변속 상태 관측은 2.5초 이내여야 한다. P + 근처 조건 6초 연속 유지 시 확인 제안. 평가 공백이 2.5초를 넘거나 위치/변속 상태가 끊기거나 대상이 바뀌면 유지 시간을 초기화한다.
- 좌표 오차/표본 한계 때문에 지오펜스는 안내 제안용이다. 하차/주차/합류 이벤트를 자동 전송하지 않는다. 자동 제안이 없어도 기존 수동 확인은 가능하다.
- 길안내 의도는 성공적으로 저장된 사용자 단계 변경에만 생성한다. 서버 동기화, 재구성, 앱 재시작만으로 요청하지 않는다.
- 단계·방문·주차장 변경으로 이전 요청 대상을 폐기한다. 연결 대기는 최대 10초, 한 번만 소비하며 화면 이탈·주행 제한·연결 실패 때 취소한다. 임의로 장시간 대기한 경로가 나중에 실행되지 않는다.
- 지도는 위치가 갱신될 때 파란 점만 이동한다. 사용자가 지도를 살펴보는 중 카메라를 매번 되돌리지 않는다. 오래된 관측은 지도에서 제거한다.

## 백엔드 / 사용자 작업

**차량 자동 제안에는 백엔드 추가 개발이 없다. 주차 후 휴대폰 합류 확인은 별도 API가 필요하다([계약](CLAUDE_CONTINUITY_BACKEND.md)).** 기존 방문 단계 API와 공유 계약을 그대로 사용한다. 동승자는 운전자가 확인한 단계만 본다.

1. 다른 에뮬레이터/기기에 앱 설치 후 ‘더 보기 → 알림·위치 허용’을 한 번 누른다. 권한 거절 시 수동 이용 가능. 반복 거절로 시스템 요청이 막히면 앱 권한 설정에서 허용한다.
2. 시연에서는 에뮬레이터 Location에서 하차 지점 `35.22669, 126.83931`, 주차장 1 `35.22620, 126.83961`을 순서대로 설정한다. 차량은 P로 두고 6초 이상 기다린다.
3. 실제 장소에서 사용할 좌표·진입구·승하차 가능 여부와 지오펜스 반경은 현장 검증한다. 현재는 추정 장소 핀과 차량 위치를 구분해서 설명한다.
4. 동승자에게 실제 차량 위치를 공유하려면 향후 위치 공유 동의/수명/접근 제어/API 계약을 별도로 설계한다. 이번 구현에는 포함하지 않았다.
